MIPS pipelined processor

Fall 2025 Hardware

Built with Verilog, AMD Vivado, FPGA

  • Designed a five-stage pipelined MIPS processor in Verilog, with fetch, decode, execute, memory, and write-back stages.
  • Pipelining lets several instructions run at once, so it gets more instructions through than a single-cycle design.
  • Built a hazard unit that handles data and control hazards by forwarding operands and stalling the pipeline when needed.
  • Synthesized the design onto an FPGA board with AMD Vivado and confirmed it works on real hardware.

NAND gate optimization

November to December 2025 Hardware

Built with Cadence Virtuoso, CMOS, analog simulation

  • Ran DC sweep simulations in Cadence Virtuoso to choose the transistor width-to-length (W/L) ratios.
  • Centered the switching threshold at VDD/2, meaning the gate flips halfway between 0 and VDD, which gives the best noise margins.
  • Compared the simulated behavior of the CMOS gates against my hand calculations.
